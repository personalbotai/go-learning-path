# Go Learning Path - Interactive Tutorial

Interactive web-based tutorial for learning Go (Golang) with code editor, simulated terminal, quizzes, and progress tracking.


## 🚀 Live Demo

Coba aplikasi secara langsung: [go-learning-path](https://personalbotai.github.io/go-learning-path/)

[![Deploy to GitHub Pages](https://img.shields.io/badge/Deploy-GitHub%20Pages-blue?logo=github)](https://personalbotai.github.io/go-learning-path/)

## Features
- 10 progressive lessons from Hello World to Interfaces
- Live code editor with syntax-like styling
- Simulated terminal output (client-side evaluation)
- Quiz section for each lesson
- Progress persistence (localStorage)
- Responsive design with Tailwind CSS
- Fully client-side (no backend required)

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- Tailwind CSS (CDN)
- Font Awesome icons
- LocalStorage for persistence
