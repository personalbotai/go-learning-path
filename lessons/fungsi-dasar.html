Fungsi Dasar

20-30 menit Modul: Fungsi

Tujuan Pembelajaran

  • Memahami konsep fungsi dasar
  • Menerapkan konsep dalam kode Go
  • Memahami best practices dalam Go

Pengantar

Fungsi Dasar adalah konsep penting dalam Go yang perlu dipahami oleh setiap developer. Go (Golang) adalah bahasa pemrograman yang dikembangkan oleh Google dengan fokus pada kesederhanaan, efisiensi, dan concurrency.

Topik yang Dibahas

  • Deklarasi fungsi dengan func
  • Parameter dan return values
  • Multiple return values
  • Named return values
  • Variadic functions dengan ...

Penjelasan

Go dirancang dengan prinsip "less is more" — bahasa yang sederhana dengan fitur yang powerful. Memahami fungsi dasar akan membantu Anda menulis kode Go yang bersih, efisien, dan maintainable.

Contoh Kode

// Contoh implementasi fungsi dasar
package main

import "fmt"

func main() {
    fmt.Println("Belajar: Fungsi Dasar")
}

Praktik Terbaik

  • Ikuti konvensi penulisan Go (gofmt)
  • Gunakan nama yang deskriptif dan jelas
  • Handle errors dengan baik
  • Write idiomatic Go code

Rangkuman

Dalam modul ini, Anda telah mempelajari tentang fungsi dasar dalam Go. Konsep ini merupakan fondasi penting untuk pengembangan aplikasi dengan Go.
