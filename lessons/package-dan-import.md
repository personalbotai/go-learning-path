## Pengantar

                
**Package dan Import System** adalah konsep penting dalam Go yang perlu dipahami oleh setiap developer. Go (Golang) adalah bahasa pemrograman yang dikembangkan oleh Google dengan fokus pada kesederhanaan, efisiensi, dan concurrency.

## Penjelasan

                
Go dirancang dengan prinsip "less is more" — bahasa yang sederhana dengan fitur yang powerful. Memahami package dan import system akan membantu Anda menulis kode Go yang bersih, efisien, dan maintainable.

                
### Contoh Kode

                
```
// Contoh implementasi package dan import system
package main

import "fmt"

func main() {
    fmt.Println("Belajar: Package dan Import System")
}

```
