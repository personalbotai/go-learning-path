# Break Continue

**ID**: `break-continue`
**Duration**: 20-25 menit

## Materi

### Penjelasan
Break Continue dalam Go adalah fitur penting untuk pengembangan aplikasi modern.

### Contoh Kode
```go
package main
import "fmt"

func main() {
    // Break Continue
    fmt.Println("Belajar Go: Break Continue")
}
```

### Praktik
Buat program Go yang menggunakan break continue.
